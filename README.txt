JOHNSTON FINE WOODWORKING — FIRST WORKING VERSION

Files:
- index.html
- style.css
- script.js
- assets/ (logo + project photographs)

HOW TO PREVIEW WITHOUT INSTALLING ANYTHING
1. Open index.html in a browser.
2. For the final live version, upload this entire folder to GitHub and deploy with GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

BEFORE LAUNCH
1. Replace YOUR-EMAIL@EXAMPLE.COM in index.html with Larry's actual email address.
2. Replace the owner bio placeholder with Larry's final bio.
3. Add a portrait or workshop photo in the Meet the Maker section.
4. Confirm final service wording and location/service area.
5. Optional: add Instagram if the business uses it.

NOTES
- The site is plain HTML/CSS/JavaScript. No Node.js is required.
- The external Google Fonts load from the web. If desired, they can be replaced with system fonts for a fully self-contained build.
- Publication links open in a new tab.
